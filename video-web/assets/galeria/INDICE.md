# Galería: escenas reales de un video de producto

Inspiración opcional. Cada archivo es una escena que funcionó, con una cabecera que explica qué
adaptar (prefijo, duraciones, imágenes, rects, tiempos y texto). Úsala tal cual, mézclala o
ignórala. Para citarla a un worker, escribe su ruta en el bloque del storyboard.

| Archivo | Sirve cuando la escena… | Usa |
|---|---|---|
| `hook-steps-to-logo.html` | abre con el problema o los pasos de un proceso que colapsan en el logo | logo blanco; 4–7 pasos |
| `window-feature-zoom.html` | muestra una pantalla y nombra 1–3 zonas con anillo y zoom | 1–2 capturas + rects |
| `cursor-click-modal.html` | cuenta que un clic abre un formulario | lista + modal |
| `split-comparison.html` | compara dos cosas (B2C/B2B, antes/después) | 2 capturas |
| `role-cards-grid.html` | presenta 3–6 roles, planes o perfiles | 1 imagen por tarjeta |
| `section-cards-flow.html` | recorre secciones de un detalle largo | 2–4 recortes + 1 vista |
| `triptych-cards.html` | resume tres ideas a la vez (respiro) | 3 recortes |
| `process-stepper.html` | explica un ciclo por etapas o días | 1 captura (+ 1 recorte) |
| `public-card-flow.html` | muestra lo que hace el cliente fuera del sistema | 2–4 tarjetas públicas |
| `admin-grid-focus.html` | enumera varias pantallas de administración | 3–5 capturas |
| `portal-type-submit.html` | muestra un formulario simple y su resultado | tarjeta vacía + resultado |
| `logo-lockup-close.html` | cierra con el nombre del producto | logo blanco (+ mascota) |
